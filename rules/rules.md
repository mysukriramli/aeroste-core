# ASD-STE100 Specification Constraints

## 1. Length Boundaries
- Procedural Steps: Maximum 20 words per sentence.
- Descriptive Text: Maximum 25 words per sentence.
- One Command Per Step: Each procedural step must contain only one active instruction.

## 2. Syntax & Punctuation
- Semicolons (;): Forbidden. Split clauses into independent sentences.
- Slashes (/): Forbidden. Replace with explicit words like "and" or "or".
- Exclamation Marks (!): Forbidden.
- Parentheses: Allowed only for official abbreviations, references, and units.

## 3. Voice & Mood
- Procedural sentences must use the imperative mood (active command).
- Passive voice is prohibited across all technical statements.
- Present participles and gerunds (-ing verb forms) are prohibited as primary action verbs.

## 4. Noun Clusters
- Noun strings of four or more consecutive nouns are strictly prohibited.
- Deconstruct noun clusters using prepositions (of, for, in, on).
